O que é o Git?

Antes de aprender comandos, é preciso entender o problema que o Git resolve. Este módulo explica o conceito de controlo de versões, a história do Git e como instalá-lo no seu sistema.

Conceito

Controlo de versão: Centralizado vs. Distribuído

Um sistema de controlo de versões (VCS) regista o histórico de alterações de um conjunto de ficheiros, permitindo voltar atrás, comparar versões e colaborar sem perder trabalho.

🗄️

Centralizado (CVCS)

Existe um único servidor central que guarda todo o histórico do projeto. Os utilizadores obtêm apenas a versão mais recente dos ficheiros. Se o servidor falhar, o histórico pode perder-se. Exemplo: SVN, CVS.

🌐

Distribuído (DVCS)

Cada colaborador tem uma cópia completa do repositório, incluindo todo o histórico. É possível trabalhar offline, criar ramos (branches) livremente e sincronizar depois com outros. O Git é o exemplo mais usado.

História

Uma breve linha do tempo

Do colapso de uma parceria de licenciamento ao sistema mais usado no mundo.

2002

BitKeeper

O kernel do Linux passa a usar o sistema proprietário BitKeeper para gerir o seu código-fonte distribuído.

2005

Nasce o Git

Após o fim do acordo de licença gratuita do BitKeeper, Linus Torvalds cria o Git em poucas semanas, com foco em velocidade e suporte a fluxos de trabalho distribuídos.

2008

Surge o GitHub

É lançada uma plataforma na nuvem para hospedar repositórios Git, popularizando a colaboração open-source através de Pull Requests.

Hoje

Padrão da indústria

O Git tornou-se a ferramenta de controlo de versões mais usada por equipas de desenvolvimento em todo o mundo.

Por que usar

Vantagens do Git

⚡

Velocidade

Operações como commit, diff e branch são executadas localmente, sem depender da rede.

🌿

Branching leve

Criar e alternar entre ramos é rápido e barato, incentivando experimentação segura.

🛟

Segurança do histórico

Cada cópia do repositório contém o histórico completo, funcionando como backup natural.

🤝

Colaboração

Várias pessoas podem trabalhar em paralelo e depois combinar o trabalho de forma controlada.

Guia rápido

Instalação do Git

Selecione o seu sistema operativo para ver os passos de instalação.

Windows

1. Aceda ao site oficial e descarregue o instalador (Git for Windows).

2. Execute o instalador e mantenha as opções padrão recomendadas.

3. Ao concluir, abra o Git Bash e confirme a instalação:

git --version

macOS

1. A forma mais simples é usar o Homebrew:

brew install git

2. Alternativamente, instalar as "Command Line Tools" do Xcode também inclui o Git.

3. Verifique a instalação:

git --version

Linux

1. Em distribuições baseadas em Debian/Ubuntu:

sudo apt update
sudo apt install git

2. Em distribuições baseadas em Fedora:

sudo dnf install git

3. Verifique a instalação:

git --version

Configuração inicial recomendada

Depois de instalar, configure o seu nome e e-mail — eles serão associados a todos os seus commits:

git config --global user.name "Seu Nome"
git config --global user.email "seu@email.com"
