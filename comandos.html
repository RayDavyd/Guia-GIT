Configuração

Definir o nome de utilizador

Define o nome que aparecerá nos seus commits, globalmente em todos os repositórios.

git config --global user.name "Seu Nome"
Configuração

Definir o e-mail

Associa um e-mail à sua identidade Git — deve coincidir com o do GitHub.

git config --global user.email "seu@email.com"
Configuração

Listar configurações

Mostra todas as configurações atuais do Git (globais e locais).

git config --list
Configuração

Editor padrão

Define o editor de texto usado para mensagens de commit, por exemplo o VS Code.

git config --global core.editor "code --wait"
Ciclo de vida

git init

Inicializa um novo repositório Git na pasta atual, criando a pasta oculta .git.

git init
Ciclo de vida

git status

Mostra o estado atual: ficheiros modificados, novos ou prontos para commit.

git status
Ciclo de vida

git add

Move alterações para a "staging area", preparando-as para o próximo commit.

git add ficheiro.txt
git add .   # adiciona tudo
Ciclo de vida

git commit

Grava as alterações preparadas no histórico, com uma mensagem descritiva.

git commit -m "feat: adiciona pagina inicial"
Histórico

git log

Lista o histórico de commits, do mais recente para o mais antigo.

git log
git log --oneline --graph
Histórico

git diff

Mostra as diferenças entre o estado atual dos ficheiros e o último commit.

git diff
git diff --staged
Histórico

git show

Mostra os detalhes e as alterações de um commit específico.

git show <hash-do-commit>
Histórico

git restore

Descarta alterações não confirmadas num ficheiro, voltando à última versão guardada.

git restore ficheiro.txt
