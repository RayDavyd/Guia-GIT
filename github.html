Git vs. GitHub & Hospedagem

Git é a ferramenta que corre no seu computador. GitHub é uma plataforma na nuvem que guarda repositórios Git e acrescenta colaboração, revisão de código e até hospedagem de sites.

Entender a diferença ← Voltar a Branches
Conceito

Git (local) vs. GitHub (nuvem)

É uma confusão comum — mas a diferença é simples.

💻

Git

É um software instalado no seu computador. Controla o histórico de versões dos seus ficheiros de forma totalmente local — funciona mesmo sem internet.

Exemplos de comandos: git init, git commit, git log.

VS
☁️

GitHub

É uma plataforma online que hospeda repositórios Git na nuvem. Acrescenta funcionalidades de colaboração: Pull Requests, Issues, revisão de código e até hospedagem de sites estáticos.

Outros exemplos de plataformas: GitLab, Bitbucket.

Comandos

Conectando local e remoto

Estes comandos ligam o seu repositório local a um repositório no GitHub.

git remote

Associar um repositório remoto

Cria um "atalho" (normalmente chamado origin) que aponta para o repositório no GitHub.

git remote add origin https://github.com/utilizador/projeto.git
git remote -v   # lista os remotos configurados
git clone

Copiar um repositório existente

Cria uma cópia local completa de um repositório que já existe no GitHub.

git clone https://github.com/utilizador/projeto.git
git push

Enviar alterações

Envia os commits feitos localmente para o repositório remoto.

git push origin main
git push origin feature/minha-tarefa
git pull

Obter alterações

Atualiza o repositório local com as alterações mais recentes do remoto.

git pull origin main
Colaboração

Pull Requests & Issues

🔀

Pull Request (PR)

É um pedido para integrar as alterações de uma branch (ex: feature/login) na branch principal (ex: main). Permite que outros membros da equipa revejam o código, comentem e aprovem antes do merge.

🐞

Issue

É um registo de tarefa, ideia ou problema dentro do repositório. Pode descrever um bug, sugerir uma funcionalidade ou organizar o trabalho da equipa — e pode ser associada a Pull Requests.

Hospedagem gratuita

Como publicar um site no GitHub Pages

Passo a passo simplificado para colocar este projeto online, gratuitamente.

Enviar o código para o GitHub

Garanta que o repositório contém um ficheiro index.html na raiz e que tudo foi enviado para a branch main.

git push origin main

Abrir as configurações do repositório

No GitHub, aceda ao separador Settings do repositório.

Aceder à secção "Pages"

No menu lateral, clique em Pages.

Escolher a branch de publicação

Em "Source", selecione a branch main e a pasta / (root). Clique em Save.

Aceder ao site publicado

Após alguns minutos, o site estará disponível em:

https://<utilizador>.github.io/<repositorio>/
